# 🧠 FocusWave Audio - Minimalist Ambient Soundscape

A lightweight, dark-mode ambient sound generator designed for deep work, coding, and high-concentration study sessions.

## 🛠️ Zero Media Files (Procedural Audio)
Unlike traditional sound machines that stream massive, slow-loading MP3 loops, FocusWave utilizes the browser's native **Web Audio API**. 
* **100% Code-Generated:** Every rumble, static wave, and click is synthesized entirely out of mathematical algorithms directly inside your browser.
* **Instant Load Times:** The entire application is under 15 Kilobytes, making it load instantly even on slow mobile networks.
* **Infinite Variations:** Because the soundscapes are generated in real-time, the audio paths never loop, avoiding the repetitive brain distractions of standard audio tracks.

## 🎛️ Audio Features
* **Brown Noise:** A heavy, deep cognitive rumble modeled to block out chaotic background environments.
* **Pink Noise:** A balanced frequency mapped to mimic soothing, static rainfall.
* **Alpha Waves (12Hz):** Dual stereo binaural beats configured to enhance structural memory recall.
* **Theta Waves (6Hz):** Slow-pulse binaural oscillators engineered to trigger deep, creative flow states.
* **Focus Clock:** A steady, minimalist mechanical ticking track built for productivity tracking.
* **Zen Hum:** A highly resonant, grounding harmonic chord layout.
